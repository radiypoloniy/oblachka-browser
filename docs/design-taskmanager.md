# Диспетчер задач — дизайн-проект

Документ до вёрстки, а не после. Первая версия экрана (31.08.2026) была собрана «по дизайн-системе»
формально: токены `card()`, `chip()`, `TEXT`, `RADIUS`, `pad`, `sp`, `motion` использованы, но рядом
насыпаны сырые числа, а половина компонентов написана заново при живых готовых. Этот док — инвентарь
того, что уже есть, чтобы переделка была механической.

---

## 1. На какой вопрос отвечает экран

Не «сколько памяти занято» — это одно число, и его видно где угодно. Экран отвечает на три вопроса,
на которые диспетчер Windows не отвечает в принципе, потому что видит восемь одинаковых строк
«Oblako»:

1. **Кто именно съел память** — вкладка, поповер, модель, ядро.
2. **Что происходит** — растёт само по себе или отпустило после действия.
3. **Что с этим сделать прямо сейчас** — усыпить, выгрузить.

Отсюда три требования, из которых растёт вся раскладка: у каждой строки есть **имя**, у чисел есть
**история**, у строки есть **действие** — но только там, где оно настоящее.

## 3. Чего в системе нет — и это надо завести, а не написать на месте

Два пункта. Оба общие, оба нужны не только диспетчеру.

### 3.1. Полоса-мера (доля от целого)

Нужна четырежды: заполнение ОЗУ, заполнение VRAM, загрузка ЦП, доля строки в общей памяти.
Готовой нет — я проверил `kit.tsx` и `widgets.tsx`.

Предложение: `Meter({ share, tone })` в `settings/kit.tsx`, рядом с прочими примитивами.
Дорожка — `well()`, заполнение — `--accent`, движение — `motion.state('width')`.

⚠️ Заполнение **акцентом**, а не статусным цветом, и это по цветовому закону: полоса показывает
величину, а не тревогу. Красная полоса при 90 % ОЗУ была бы статусом, который красит фон, — этого у
нас нет по правилу.

### 3.2. Строка с числовыми колонками

`SpotLine` даёт «имя слева, контрол справа». Диспетчеру нужны выровненные по правому краю числовые
колонки (занято / рабочий набор / ЦП) — иначе таблица не читается вертикально.

Предложение: расширить `SpotLine` необязательным `cols?: React.ReactNode[]`, а не заводить второй
компонент. Геометрия та же, добавляется только средняя часть сетки.

⚠️ Если это покажется натягиванием на чужую задачу — тогда отдельный `DataRow` там же в `kit.tsx`.
Решать тебе; я склоняюсь к расширению `SpotLine`, потому что «имя, уточнение, действие» у них общее,
а расходятся они ровно на колонках.

## 4. Что в первой версии было сделано неправильно

Список конкретный, чтобы переделка была вычёркиванием.

**Написано заново при живом готовом:**

| Мой компонент | Чем заменяется |
| --- | --- |
| `Trend` (49 строк SVG) | `Sparkline` — у неё та же плавающая шкала по min/max, та же заливка градиентом и свой id на экземпляр (у меня id не было бы вовсе) |
| `Metric` | `Fact` + `FactGrid` |
| `Row` | `SpotLine` (+ колонки из 3.2) |
| ярлык вида | `MonoChip` |
| `actionStyle` | `btnTone` |
| `Fill` | `Meter` из 3.1, один раз в систему |

**Сырые числа вместо токенов** — `taskmanager.tsx`: `fontSize: 26` (стр. 107), `gap: 3` (147),
`gap: 5` (166), `height: 4` в полосе, `size={13}` у иконок (184, 189), `strokeWidth={1.4}` (78),
`opacity: 0.55` (144), колонки сетки `92px 92px 64px 92px`, `H = 40` у графика.

⚠️ Правило CLAUDE.md: «в компонентах цифр размера быть не должно — только `sp()`, `pad()`, `RADIUS`,
`TEXT`, `motion`». Машина его **не ловит**: `conventions-check` проверяет запрет сырых чисел только
в файлах настроек. То есть на остальной интерфейс правило действует, но держится на человеке —
и это отдельный повод расширить проверку (см. раздел 6).

## 5. Цветовой закон на этом экране

- **Акцент** — заполнение полос и точка активной вкладки. Это величина и «вот эта», а не состояние.
- **Статус** — не используется вовсе. Соблазн покрасить строку-обжору красным есть, но по закону
  статус не красит фон, а «много памяти» — это не ошибка, это факт. Обжора и так первый в списке.
- **Земля и поверхности** — `Panel`, `well()`, `--surface-sunken`.
- **Спящая вкладка** — приглушением, а не цветом.

⚠️ Отдельно: строка «Локальная модель» просится быть выделенной — она самая дорогая и самая
управляемая. Выделять её цветом нельзя (это был бы четвёртый смысл цвета), поэтому выделяется тем,
что у неё единственной есть кнопка «Выгрузить».
