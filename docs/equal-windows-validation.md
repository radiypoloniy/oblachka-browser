# Итоговая проверка равноправных окон

Реализация завершена 5 октября 2026. Исследование исходного поведения и решение по закреплениям: `equal-windows-plan.md`.

В каждом окне доступны одинаковые вкладки, закрепления, группы, split, поиск, перевод страниц, группировка, полноценная AI-панель, Hub, Notebook и граф. Оконные команды используют владельца интерфейса. Общие настройки, профильные хранилища, VPN, модель и очередь принадлежат приложению; инициализация выполняется однократно. Legacy-роль первого окна сохранена только для стартового выбора профиля.

Один координатор сохраняет сессию v6 со всеми окнами и защищённой миграцией. Закрытое окно с закреплениями сохраняется для продолжения; его можно восстановить из меню. Перенос сохраняет стабильный id, live-view, закрепление, профиль и состояние страницы, а отказ приёмника возвращает исходное дерево.

Сборка и оба TypeScript-таргета прошли. Полный `npm test` запускается обязательным pre-commit hook каждого коммита. Рабочий профиль пользователя в этих прогонах не запускался и не изменялся.

Пределы проверки: управляемые ответы проверяют адресацию и отмену, а не качество перевода и генерации; отдельно проверен реальный локальный инференс на установленной модели. Аппаратное отключение, завершение сеанса ОС, реальный OAuth, обновление приложения и macOS требуют проверки соответствующих окружений; они не имитируются этими стендами.
