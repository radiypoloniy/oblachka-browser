# Первый этап переработки поиска истории

Исправлена подмена результата: когда модель отвергает все страницы, сохранённые совпадения
по заголовкам и адресам подписываются «Обычные совпадения», а не «По смыслу».
Недоступность AI объясняется отдельно. При успешном ответе сохраняется семантическая выдача.
Дополнительных вызовов модели, SQL-запросов и изменений формата истории нет.

Проверки: сборка, типы обоих таргетов, history-search-reuse и живой
history-search-fallback-drive на одноразовом профиле. Полный npm test: 125/126;
structure сообщает прежние превышения размеров файлов. Новый тест сначала неправильно
считывал заголовок через innerText (CSS переводит его в верхний регистр); после перехода
на textContent все четыре сценария прошли.

Для анонса после устранения ограничения просмотра истории:

«Начали переработку поиска в истории Oblako. AI-поиск теперь различает результаты,
подтверждённые моделью, обычные совпадения и недоступность AI. Это первый этап:
дальше улучшаем поиск страниц по описанию и проверку условий запроса».

Это ещё не новый механизм извлечения кандидатов: расширение запросов и отмена генерации
из плана пока не реализованы. Новая публикация релиза в этом заходе не выполнялась.
