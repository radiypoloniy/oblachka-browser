# Hub, Notebook и граф в нескольких окнах

Контекст Hub получает ключ окна вместо общего `hub`. Сохранённые беседы остаются в общей базе, но живые истории и ожидающие ответы независимы. Новый чат, возобновление, удаление сессии и закрытие окна отменяют прежний запрос; отменённый результат не записывается. Запросы от чужих страниц и произвольных вкладок не выбирают контекст Hub.

Notebook читает открытую страницу своего окна и не извлекает приватную вкладку для сохранённого источника. Один веб-узел графа получает отдельную WebContentsView в каждом окне; его ссылки открываются у своего владельца. Закрытие окна освобождает только его страницы.

В каждом окне доступны группировка, Notebook, граф и подготовка AI-обзора. Роль первого окна пока используется только для однократной инициализации и стартового выбора профиля.

`scripts/multiwindow-hub-drive.mjs`: реальный Electron и временная SQLite-база, управляемые ответы через настоящую QwenQueue. Проверены отдельные истории и записи, продолжение каждого диалога, отмена без поздней записи, закрытие первого окна, извлечение одинакового URL из своего окна, две независимые страницы одного узла графа. Полная сборка и оба TypeScript-таргета прошли.
