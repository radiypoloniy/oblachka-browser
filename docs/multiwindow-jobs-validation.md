# Отмена задач Студии и графа по владельцу

Генерация Студии получает сигнал закрытия заказавшего окна. Activity связывает его только с конкретной работой, поэтому закрытие окна не отменяет соседнюю очередь. Документ проверяет отмену после ожидания сборщика; даже поздний успешный результат не отдаётся закрытому заказчику. Activity и оконные слушатели освобождаются в `finally`.

Один граф имеет один прогон, поскольку его результаты общие в SQLite. Второй запрос того же графа получает явную ошибку занятости. Разные графы могут ждать общую QwenQueue независимо. Закрытие владельца или отмена графа прерывает его генерацию; проверка после ответа предшествует записи результатов и истории. Уже завершённые узлы сохраняются, текущий отменённый узел сохраняет прежний результат. Общий runtime продолжает работать.

`scripts/multiwindow-jobs-drive.mjs` прошёл на временной SQLite-базе: две работы Студии, закрытие первого окна, независимость Activity и очереди второго; отмена графа с прежним результатом без поздней записи/версии; отказ второго прогона того же графа; успешный другой граф и повторный запуск; отмена многошагового документа с поздним успехом сборщика. Ответы управляемые, очередь и менеджеры настоящие.
