# Перевод и группировка в нескольких окнах

Перевод и запрос группировки разрешаются по отправителю IPC. Состояние перевода хранится по стабильному id вкладки; перенос не отменяет работу, навигация (в том числе фоновая) и закрытие отменяют её. Старый ответ проверяется после ожидания движка, до изменения DOM. Прогресс приходит только владельцу активной вкладки. Закрытие окна отменяет его запрос группировки.

Проверено `scripts/multiwindow-tools-drive.mjs` в реальном Electron с временным профилем: два одновременных перевода, независимость DOM и состояний, перенос во время ответа, возврат оригинала, отмена при фоновой навигации, группировка дерева второго окна после закрытия первого. Движок перевода и ответ группировщика управляемые; это проверка адресации и отмены, а не качества модели.
