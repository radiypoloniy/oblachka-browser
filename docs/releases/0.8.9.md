# Oblako 0.8.9

Начали переработку поиска в истории. Классический поиск остаётся быстрым способом найти
страницу по заголовку или адресу; поиск с ИИ помогает искать по смыслу сохранённого текста.
В этом выпуске улучшили подготовку данных для ИИ и отзывчивость истории. Работа продолжается.

## История без ограничения в 500 записей

Теперь можно просматривать всю сохранённую историю и следующие страницы результатов
обычного поиска. Кнопки «Старее» и «Новее» переключают порции записей: большой архив не
загружается в интерфейс целиком. Чтение истории и полнотекстовый поиск выполняются в
отдельном потоке, а устаревшие запросы при быстром вводе пропускаются до обращения к базе.

## Первые улучшения AI-поиска

- ИИ получает фрагменты сохранённого текста, подобранные под запрос пользователя.
- Улучшена подготовка поисковой темы из запросов, сформулированных обычной фразой.
- Улучшен поиск числовых последовательностей: версий, номеров и похожих обозначений.
- Обычные совпадения больше не выдаются за страницы, подтверждённые ИИ. Отказ по смыслу
  и недоступность модели объясняются отдельно; полезные совпадения остаются доступны.
- Убраны повторные чтения одних и тех же кандидатов при подготовке AI-выдачи.

Расширение запросов, новая проверка условий и отмена устаревшей генерации — следующие
этапы работы. Они не заявляются как готовые возможности 0.8.9.

## Другие изменения

- Добавлены сворачиваемые AI-карточки активной страницы с настройками модели и бюджета.
  Улучшена подготовка материалов для карточек и их отображение в боковой панели.
- Исправлены отдельные сценарии перехода видео в полный экран и поведения оверлеев.
- Исправлена активация вкладок, открытых из контекстного меню страницы.
- Улучшено редактирование подсказок адресной строки и группировка действий с изображениями.
- Обновления можно отклонить; уже скачанный установщик сохраняется для повторного запуска.
- Исправлены отдельные проверки безопасности внешних действий и операций с паролями.

Изменения истории не требуют миграции базы. AI-поиск использует уже сохранённый текст:
не каждая посещённая страница обязательно имеет полный текст в индексе.

Windows x64: установщик и ZIP без установки.
