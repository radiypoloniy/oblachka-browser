# Проверки Oblako 0.9.0

Дата: 5 октября 2026. Рабочий профиль пользователя не открывался: живые проверки
использовали отдельные временные профили.

- Production build и обе проверки TypeScript выполнены успешно.
- Финальный полный npm test: 137/137, 3626 ассертов, 0 провалов.
  Отчёт сохранён локально в release/tests-0.9.0.log. После успешного ручного
  полного прогона релизный коммит выполняется без повторного запуска pre-commit;
  предыдущие попытки хука останавливались на нестабильных живых проверках.
  В диагностическом прогоне 136/137: history-query-ui остановился на ошибке CDP
  Promise was collected, не на проверке результата. На отдельном повторе прошли
  все четыре сценария очереди, закрытия вкладки, AI и смены профиля.
  Синхронные команды этого стенда переведены на существующий evalMainSync:
  ожидание Promise для пустого результата не требуется и вызывало сбой Inspector.
- Упаковка Windows x64: установщик, ZIP, blockmap и latest.yml версии 0.9.0.
  Первый npm run dist остановился на TLS-ошибке загрузки Electron. Финальная упаковка
  выполнена через API electron-builder с electronDist=node_modules/electron/dist:
  установленный Electron 42.8.1, тот же конфиг electron-builder.yml, publish=never.
  Версия собранного Oblako.exe: 0.9.0.
- packaged-release-drive: успешно; интерфейс, IPC, сохранение и чтение пароля
  через нативный SQLite, постраничная история в упакованном приложении.
- Релизный живой прогон: первоначально 15/19. Все четыре упавших сценария
  успешно выполнены отдельно; не заявляем один полностью зелёный широкий прогон.
  history-search-fallback получил управляемый ответ расширения запроса, чтобы
  тест запасной выдачи не запускал реальную модель. multiwindow-tools теперь
  связывает ответы перевода с текстом страницы, не с порядком асинхронных батчей.
  session-downgrade перезапускается без задержки после подмены файла, чтобы
  debounce автосейва не перезаписывал собственную тестовую сессию.
  window-lifecycle прошёл на отдельном повторе после ошибки CDP Promise was collected.
- Защита неизвестной версии сессии: копия побайтово совпадает с исходником,
  незнакомые поля сохраняются, основной файл защищён от перезаписи.
- Прошли сценарии многооконных Hub, AI-панелей, поиска, оверлеев и фоновых задач,
  маршрутизации оконных команд, переноса вкладок, сессии и перезапуска.
- reopen-window и closed-tab-privacy: порядок восстановления окно/вкладка,
  хоткей из chrome/страницы, группы/закрепления/геометрия, отсутствие дублей,
  технические закрытия, отмена close, немедленный автосейв, исключение
  инкогнито/OAuth, cookies исходного профиля живой и спящей вкладки.

Длительная генерация на реальных GGUF-моделях в этом релизном проходе не выполнялась.
Публичное описание возможностей: 0.9.0.md.
