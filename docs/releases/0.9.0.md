# Oblako 0.9 — несколько окон, один браузер

Главное в этом выпуске — полноценная работа с несколькими окнами. Можно разделить
задачи по окнам, переносить вкладки между ними и продолжить работу после перезапуска.
Ещё один шаг к первой стабильной версии!

## Полноценная многооконность

- Открывайте новые окна через Ctrl+N. В каждом доступны Hub, AI-панель, графы и Studio,
  быстрый поиск, перевод страниц и организация вкладок.
- Переносите вкладки между существующими окнами или в новое окно. Живая страница
  переезжает вместе с историей переходов, заполненными формами, профилем, закреплением
  и состоянием звука — без повторного открытия по адресу.
- После перезапуска возвращаются все сохранённые окна с вкладками, группами,
  разделённым экраном, закреплениями, размером и положением.
- AI-чаты и команды интерфейса работают в своём окне. Закладки, загрузки,
  настройки и другие общие данные обновляются во всех окнах.

## Ctrl+Shift+T возвращает и окна

Хоткей восстанавливает последнюю закрытую вкладку текущего окна или последнее
закрытое окно браузера — в зависимости от того, что было закрыто позже. Окно
возвращается целиком. Повторные нажатия продолжают восстановление по порядку.

Та же команда доступна по ПКМ на кнопке новой вкладки. В подменю «Закрытые окна»
можно выбрать конкретное окно.

## Поиск в истории стал точнее

- Добавлены фильтры по сайту и периоду.
- Ускорен обычный поиск, в том числе совпадения внутри слов и адресов.
- AI-поиск лучше подбирает фрагменты сохранённых страниц и обрабатывает запросы
  обычной фразой. Для поисковых моделей, которые поддерживают эту возможность,
  добавлено расширение запроса.
- Устаревшие поисковые запросы отменяются; неполный ответ модели не выдаётся
  за готовый результат. Используется выбранный поисковый провайдер.
- При повторном посещении обновляется сохранённый текст страницы; доступен поиск
  по одной предыдущей сохранённой версии содержимого.

## Надёжность и приватность

- Инкогнито и временные страницы авторизации не попадают в обычное восстановление.
- Закрытая вкладка возвращается в исходном профиле, с его сессией сайтов.
- Автоматическое закрытие пустого окна после переноса вкладки не засоряет историю.
- Исправлено сохранение адреса восстановленной вкладки до окончания её загрузки.
- Улучшена защита многооконной сессии и резервных копий при запуске старой версии браузера.
- Закрытие одного окна не останавливает общие сервисы, пока остаются другие окна;
  отменённый выход сохраняет рабочее состояние браузера.

Windows x64: установщик и ZIP без установки.
