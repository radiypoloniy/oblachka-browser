# Проверки Oblako 0.9.2

Дата: 8 октября 2026. Исправление поиска по странице и карточки паролей.
Формат сейфа, сессии и профиля не изменён.

- Причина поломки Ctrl+F установлена по коду: с `e2b26ea` вью FindBar не была
  зарегистрирована владельцем окна, `tabsOf` отдавал null, `findInPage` не вызывался.
  Новая проверка `overlay-owner-check`: 11/11; на коде без исправления краснеет.
- Обе проверки TypeScript прошли (renderer и main).
- Профильные проверки: contract, contrast, conventions, doc-markup, motion,
  overlay-owner, overlay-shadow, radius, structure, typography, lint, password-*
  (breach, fill, indicator, origin), tab-find, ui-language, settings-* — все зелёные.
  Полный `npm test` и `npm run drive` в этот выпуск не гонялись: среда, где делались
  правки, не поднимает нативные модули и Windows-сборку Electron.
- Карточка паролей проверена рендером компонента в Chromium на 280 px, светлая и
  тёмная темы, русский и английский: переполнения нет, все четыре состояния карточки.
- Windows x64 упакован через electron-builder с исходным electron-builder.yml и
  electronDist=node_modules/electron/dist (Electron 42.8.1). Созданы EXE, ZIP, blockmap
  и latest.yml; sha512 в latest.yml совпадает с установщиком; в app.asar версия 0.9.2,
  в собранном `FindBarManager.js` есть регистрация владельца.
- Живая проверка Ctrl+F и карточки сохранения пароля в установленной сборке — за
  автором перед публикацией.
