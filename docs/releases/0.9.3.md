# Oblako 0.9.3 — чат AI-панели без привязки к странице

- **Беседу можно отвязать от страницы.** Крестик на плашке над лентой уводит чат с текущей
  вкладки, клик по заголовку плашки открывает выбор: текущая страница, один из ваших наборов
  контекста или пустой чат. Отвязанная беседа не сбрасывается ни при переключении вкладок, ни
  при переходе по ссылкам; беседа страницы при этом остаётся во вкладке.
- **Наборы контекста** — Настройки → AI → «Наборы контекста». Инструкции и материал, которые
  модель получает вместо страницы, например «отвечай на присланные сообщения в такой-то
  стилистике». Набор по умолчанию открывается в панели первым. Наборы хранятся на диске и
  переживают перезапуск; до 12 000 символов на набор.
- В отвязанной беседе скрыты действия над страницей: перевод, фактчек, скиллы и «Важное на
  странице».

Формат сейфа, сессии и профиля не меняется. Наборы лежат отдельным файлом `ai-contexts.json`
в папке профиля. Обновление — через встроенный апдейтер или установкой поверх 0.9.2.

Windows x64: установщик и ZIP без установки.
