# Проверки Oblako 0.9.4

Дата: 9 октября 2026. Импорт контекста из файлов и перетаскивание изображений в AI-чат.

- Прод-сборка, оба таргета TypeScript и проверка сетевого маршрута main прошли.
- `npm test`: 142 проверки, 3716 ассертов, без ошибок. Штатный pre-commit также выполнен.
- Изолированные проверки: импорт JSON и Markdown через редактор — 5 случаев; вложения —
  31 случай (скрепка, второй ход, облачные форматы, дроп URL и файла, `blob:`, очистка во время
  загрузки, сохранение обычного текстового дропа); живая проводка IPC — 7 случаев.
- `npm run dist` собрал установщик, ZIP и blockmap. Версия EXE и `package.json` внутри ASAR —
  0.9.4. Проверены 1008 собственных JS/map/JSON файлов ASAR: точных фрагментов удалённого
  приватного шаблона и исходной переписки нет. В опубликованную историю не включаются локальные
  коммиты, в которых эти материалы присутствовали.
- История, закладки, сессия, сейф и набор по умолчанию боевого профиля не изменялись.
  Все живые проверки используют временные профили.

Исходный полный живой прогон перед текущими правками: **54 из 65** прошли.
Незелёные сценарии: `compare-model`, `multiwindow-session`, `page-insights`,
`page-insights-model`, `page-insights-preparation`, `reopen-window`, `split-group-enter`,
`suggest-dropdown`, `tab-compare`, `tab-compare-wb`, `update-prompt`.
Два модельных драйвера требуют отдельного пути к GGUF, который общий запуск не передаёт.
Остальные провалы включают CDP (`Promise was collected` / отсутствие execution context),
проверки восстановления окон и ожидания карточек/характеристик страницы.

Заключительный полный живой прогон: **53 из 66** прошли, 419 ассертов прошли, 4 не прошли.
Все четыре неуспешных ассерта относятся к снимку страницы в MCP: Chromium возвращает
`Current display surface not available for capture`. Незелёные сценарии:
`calendar-flicker` (таймаут 180 секунд), `compare-model`, `mcp`, `multiwindow-session`,
`page-insights-dynamic`, `page-insights-model`, `page-insights-preparation`, `password-popover`,
`reopen-window`, `split-group`, `split-group-enter`, `suggest-dropdown`, `update-prompt`.
`tab-compare`, `tab-compare-wb` и `page-insights`, упавшие в исходном прогоне, в заключительном
прошли. Общий прогон не является полностью зелёным; устранение этих сбоев не включено в выпуск.

Свежий упакованный 0.9.4 прошёл `packaged-release`: запуск интерфейса, IPC, SQLite сейфа и
экран истории на временном профиле. Контрольная сумма SHA512 в локальном `latest.yml`
соответствует установщику.

Drop URL/файла проверен через события DOM в настоящей панели. Разовый тест доверенного
нативного перетаскивания со страницы через CDP не смог инициировать dragstart Chromium;
проверка жеста мышью между двумя WebContentsView остаётся ручной.
