# Проверки Oblako 0.9.5

Дата: 21 октября 2026. Поле ввода AI-чата, повторный запуск во время выхода, полноэкранное видео.

- Прод-сборка и оба таргета TypeScript прошли.
- `npm test`: 143 проверки, 3724 ассерта, без ошибок. Штатный pre-commit выполнен на коммите
  `c0b81d7`; коммиты `213b988` и `1780e38` шли с `--no-verify`, потому что хук проверяет рабочее
  дерево, а там лежали тогда ещё незакоммиченные правки полноэкранного режима с двумя устаревшими
  проверками (`tab-hotkeys`, `tab-page-lifecycle`). Обе проверки обновлены в `c0b81d7`.
- Новая проверка `second-instance-check`: 7 случаев решения о повторном запуске.
- Новый живой драйвер `second-instance-drive` на временном профиле: вкладки → закрытие окна с
  задержкой выхода на 4 с (имитация остановки VPN) → второй запуск на том же профиле → перезапуск,
  те же вкладки, одно окно; 5 из 5. Обратный ход: со старым поведением драйвер краснеет —
  уходящий процесс поднимает пустое окно, перезапуска нет.
- Живые `fullscreen-panel` (5 проверок) и `youtube-fullscreen` прошли. Второй только снимает
  замеры; плавность входа и выхода проверяется глазами.
- Поле ввода AI-чата живьём автором выпуска не проверялось — только сборка и типы.
- `npm run dist` собрал установщик, ZIP и blockmap. Свежий упакованный 0.9.5 прошёл
  `packaged-release` на временном профиле. `latest.yml`: версия 0.9.5, путь и размер совпадают с
  установщиком.
- История, закладки, сессия и сейф боевого профиля не изменялись. Все живые проверки используют
  временные профили.

Полный живой прогон `npm run drive` для этого выпуска не выполнялся.
