# Проверки Oblako 0.9.6

Дата: 27 октября 2026. Фильтры блокировщика из первоисточников, Electron 44.

- Прод-сборка и оба таргета TypeScript прошли.
- `npm test`: 143 проверки, 3725 ассертов, без ошибок; штатный pre-commit выполнен на `5917b0b`.
- Застывшие фильтры подтверждены сравнением ПРАВИЛ, а не дат: скриптлеты для `youtube.com/watch`
  в кэше от 9.08 и от 25.10 совпали один в один; зеркало Ghostery не обновлялось с 14.08.2026.
  Движок из первоисточников, собранный во временной папке, даёт 34 актуальных скриптлета, все
  находятся в `resources.json`.
- Новый случай `scriptlet-bundle-check`: семь обёрток `JSON.stringify` дают 8 вызовов. Обратный
  ход: без общего `safeSelf` из 2.20 — 128.
- Живой YouTube проверен пользователем на сборке разработки: видео запускаются, плашки
  «Возникли неполадки?» нет. До правки отключение блокировщика на youtube.com лечило симптом.
- Electron 44 — проверки подъёма в коммите `1a60139` (`npm run drive` 61/67; три падающих
  драйвера падают и на 42 при том же коде). Сборку на 44 пользователь щупал с 22.10.
- `npm run dist` собрал установщик, ZIP и blockmap. Свежий упакованный 0.9.6 прошёл
  `packaged-release` на временном профиле. `latest.yml`: версия 0.9.6, путь и размер совпадают с
  установщиком.
- История, закладки, сессия и сейф боевого профиля не изменялись. Прежний файл кэша
  блокировщика остаётся на диске и больше не читается.

Полный живой прогон `npm run drive` для этого выпуска не выполнялся.
