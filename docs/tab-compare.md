# Сравнение товаров

Откройте 2–5 похожих товаров. Для новой комбинации вкладок один раз появляется короткое
предложение «Помочь выбрать?» с кнопками «Сравнить» и «Не сейчас». Постоянной кнопки
в тулбаре нет. Повторный запуск доступен в существующей AI-панели только при наличии
похожих открытых товаров. Одобренный макет — `visual docs/tab-compare-concept-v2.html`.

Разбор открывается отдельной вкладкой, в парящем острове с отступами и радиусами общей
дизайн-системы. Первый раздел — короткое саммари, до трёх советов для разных задач и до
двух оговорок. У каждого совета раскрывается основание: реальные факты, цитаты и переход
к исходной странице. Второй раздел — характеристики, фильтр различий и источники.

## Данные и цена запроса

- Фоновый проход раз в 6 секунд проверяет до 20 обычных открытых вкладок текущего окна.
  Инкогнито, спящие вкладки, скрытые/свёрнутые окна исключаются. Результат определения товара
  кешируется на 60 секунд, отсутствие товара — на 12 секунд. Страницы без признаков товара
  отсекаются до обхода таблиц и чтения текста.
- Обнаружение не загружает модель и не отправляет запросы. Предложение не показывается
  автоматически в полноэкранном режиме, поверх другого поповера или при вводе на странице.
- Только нажатие «Сравнить» заново читает выбранные карточки. Без AI запросов нет;
  с AI выполняется один запрос на саммари, советы и сопоставление характеристик, максимум
  2400 выходных токенов. Используется модель, выбранная для работы со страницами. Без
  настроенной модели доступны исходные данные и предложение подключить локальный или
  облачный AI. Выбор модели доступен через обычный ModelChip. Ручное обновление повторяет
  чтение и запрос; прежний разбор остаётся доступен во время обновления.
  Лимит ожидания — две минуты для облака, четыре для локального подключения с учётом CPU.
- В облако передаются заголовки и найденные характеристики, а не весь текст страницы,
  формы, cookies или история. Расход проходит через обычный учёт AI-провайдера.
- Модель возвращает ссылки на найденные факты. Значения характеристик и раскрываемые
  цитаты берутся из снимка страницы. Саммари должно ссылаться как минимум на два товара;
  совет — на рекомендуемый вариант. Ответ без действительных оснований отклоняется.
  Повторение названий полей вместо объяснения и одинаковые сценарии отсекаются.
  Это проверка ссылок, а не доказательство правильности всех выводов модели: текст советов
  и сопоставление характеристик всё равно могут ошибаться. При ошибке первого запроса
  доступны факты, при ошибке обновления сохраняется прежний разбор с сообщением об ошибке.
- Закрытый источник, смена URL или обнаруженное изменение фактов помечают снимок устаревшим.
  Самостоятельного платного повторного запроса нет. Изменения на том же URL проверяются
  при возвращении к товарной странице с учётом фонового кеша; это не мониторинг цен в реальном времени.

## Извлечение

Общий путь: корневой Product / Product в @graph из JSON-LD, видимые таблицы характеристик,
definition lists, цена из видимой карточки. Видимые данные выбранного варианта приоритетнее
SEO-разметки. Вложения Product внутри выдачи/рекомендаций не считаются текущим товаром.

Для Wildberries используется отдельный адаптер актуального DOM. После явного запуска
сравнения браузер открывает «О товаре» в исходной вкладке, читает таблицу характеристик
и закрывает открытый им drawer. Уже открытый пользователем drawer не закрывается.
Это не добавление в корзину и не запрос к закрытому API. При смене разметки сайта адаптер
может потребовать обновления. Цена другого продавца у распроданного товара не используется.
Цена с кошельком/условиями сохраняется текстом; автоматического выбора «самой дешёвой» нет.

Не все магазины используют поддерживаемую разметку. Если данных мало, это обозначено
в данных; отсутствующие характеристики остаются пустыми. Для WB без открытых характеристик
фоновое определение может опираться только на цену/наличие, полный набор читается по кнопке.

## Хранение и выключение

История → Сравнения — карточки сохранённых разборов, поиск по названиям, описанию и
источникам. Список загружается порциями по 60 записей. Из открытого разбора сюда ведёт
кнопка «Все сравнения».

Каждый профиль хранит свой архив в отдельном `comparisons.sqlite`. Сначала сохраняются
исходные факты, затем результат AI. Карточка остаётся после закрытия вкладки и перезапуска.
Открытие показывает сохранённый снимок без вызова модели и без загрузки сайтов. Если
источник уже закрыт, он открывается только по явному переходу к нему или обновлению.
Обновление меняет тот же разбор, не создавая дубликат. Старый снимок обозначается явно.
Автоматического удаления нет; кнопка удаления на карточке удаляет только выбранный разбор.
Ошибка сохранения показывается в открытом сравнении, сам результат остаётся доступен.

Настройки → AI → Сравнение товаров: выключение останавливает фоновое обнаружение,
сохранённый архив остаётся доступен. Формат сессии, база истории и существующее
отслеживание цен не меняются.

## Проверки

- `node scripts/tab-compare-check.mjs` — разметка, варианты/условия цены, ограничения,
  защита от недостоверных ссылок модели.
- `node scripts/compare-advice-check.mjs` — проверка ссылок на реальные факты, границ
  количества советов и оговорок, отклонение неподтверждённого ответа.
- `node scripts/compare-archive-check.mjs` — проверка сохранённого формата, ссылок
  на факты и отклонение повреждённых записей; запускать после сборки.
- `node scripts/compare-model-drive.mjs <путь к GGUF>` — ручная проверка настоящего
  ответа локальной модели в отдельном CPU-контексте, без записи в пользовательский профиль.
- `node scripts/tab-compare-drive.mjs` — отдельный профиль Electron: короткое предложение,
  сценарий без модели, саммари, советы, источники, различия, один вызов тестового облачного
  провайдера по нажатию, повторный запуск из AI-панели, обновление, ошибка и устаревание снимка.
  Проверяет восстановление после перезапуска без AI, поиск, отдельные архивы профилей,
  удаление, открытие закрытого источника и карточки в узком окне с тёмной темой.
- `node scripts/tab-compare-wb-drive.mjs` — ручная сетевая проверка настоящих карточек WB,
  чтения скрытой вкладки и восстановления drawer. Требует доступного сайта и актуальных карточек.

Проверка новой версии: сборка, оба TypeScript-таргета и живой стенд прошли. Общий прогон:
116/117, прежний `structure-check` падает на размерах старых файлов; новых нарушений нет.
В отдельном CPU-контексте Qwen 3.5 4B не завершила разбор за четыре минуты (первый токен
через 151 секунду при входе 538 токенов). Это не измерение GPU-пути; его скорость пока не проверена.
Маленькая EuroLLM дала формально корректный, но бессодержательный ответ: такие ответы теперь
отклоняются. Живой стенд проверяет облачный путь тестовым провайдером без платных запросов.
