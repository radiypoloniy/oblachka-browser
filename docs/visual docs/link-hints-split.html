Одна идея: открыть ссылку в соседней половине без мыши

Нажмите «Метки ссылок» или Alt+G. Потом нажмите букву у нужной ссылки. Esc отменяет.

Идея меток: Surfingkeys. Открытие в split уже есть в Oblako.

WebContentsView

Область для отображения веб-страницы внутри окна. Именно такой слой Oblako использует для вкладок и двух сторон split.

const view = new WebContentsView()
win.contentView.addChildView(view)

Работа с представлением

У view есть собственный webContentsG. Его можно загрузить по адресу и слушать события навигации. Размер задаётся через setBoundsH.

Если нужно открыть связанную страницу, сейчас это можно сделать через контекстное меню ссылки: «Открыть в другой половине». Метки предлагают тот же результат с клавиатуры.
