Листы в папке, не шапка над сайтом

Текущая страница остаётся страницей. То, что лежит под ней, видно кромками в уже оплаченных 36 пикселях шапки. Клик раскрывает стопку веером поверх панели — без второй полосы, без отъема высоты у сайта и без цветных колод на весь экран.

Как это работает

Остров — это папка

ПокойТекущий лист — живая страница. Нижние торчат кромками в шапке. Если в половине одна вкладка, кромок нет: нечего открывать.
КликСтопка выезжает из-под шапки веером. Каждый лист — бумага с цветным корешком сайта, а не серый прямоугольник с жёлтой полосой сверху.
ВыборНажали лист — он встаёт наверх, остальные заезжают обратно. Соседняя половина не двигается.
СбросНа страницу — показать здесь, прежняя уходит вниз. На кромки — положить под низ, текущая не меняется. На шапку соседней — поменять половины.
Посадка в код

Ничего не отнимаем у страницы

Шапка остаётся SPLIT_HEADER_HEIGHT = 36. Кромки заменяют кнопку ▣. Веер рисуется в уже существующем SplitStackPopover — нативной вью поверх гостя, потому что CSS под страницей не нажать.

Снимки страниц для веера не берём. capturePage уже стоит дорого на жесте переноса половины; стопка из пяти вкладок превратила бы клик в паузу. Цвет — siteHue(host), кромка листа сверху, не заливка острова. Фиолетового в наборе нет.

Список в переключателе — то, что сейчас в splitstack.tsx. Его можно оставить запасным, но веер — целевой вид.
