Oblako · split · ходы, не пункты меню

Зачем две папки

Папка с переключением листов — это уже интересно. «Ссылка откроется в сплите» — нет: это один скучный ход из колоды, которую вы придумали. Ниже стол. Нажмите ход — не карточку с IPC.

Почему это не «ещё один браузер с split»

Две живые страницы есть у всех. Папка на половине есть почти ни у кого: стопка у нас уже сериализуется, просто ведёт себя как молчаливый список за ▣.

Интересное начинается, когда лист — не вкладка сайдбара, а карта на столе. Тогда перевод, прошлый визит и «вы это уже читали» становятся типами карт, а не пунктами в трёх разных меню.

Рельсы те же

  • Две половины. Третья карта уходит в папку, не в третью колонку.
  • Кромки — в 36px. Веер — в уже существующем SplitStackPopover.
  • Близнец перевода греет Bergamot на той вью, не переписывает эту.
  • «Из памяти» и «два кармана» — карточка подтверждения. Модель предлагает.
  • Столы — это уже припаркованные splitPairs. Имени в session.json нет.

Не делаем: сетку, синхронный скролл, раздел настроек, перехват каждого клика, снимки через capturePage.
