Продуктовое правило

Шапка показывает текущую страницу. Кнопка «Стопка» открывает выбор вкладок для этой половины. «↶» возвращает непосредственно вытесненную вкладку одним нажатием. Новая ссылка остаётся в сайдбаре и появляется в стопке источника.

Что проверить в реальном UI

  • Понимают ли люди разницу между «↶» и браузерным «Назад»?
  • Находят ли новую ссылку без подсказки?
  • Не перегружает ли шапку кнопка стопки на узком окне?

Границы концепта

Группа остаётся в сайдбаре. В слоте видна одна её вкладка за раз; второй слот независим. При переносе внутренний split группы распадается на две обычные вкладки и появляется в стопке. Это отдельное структурное действие, которое нужно учитывать при сохранении сессии.

Попробуй перетащить группу или отдельную вкладку на любую половину, открыть «Стопку», нажать «↶», открыть ссылку на странице и потянуть разделитель. Кнопки сценариев задают исходные состояния для проверки.
