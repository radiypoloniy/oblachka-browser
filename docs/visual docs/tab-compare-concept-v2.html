Подключите AI для советов

Характеристики уже собраны. Чтобы объяснить различия и предложить варианты под вашу задачу, нужна локальная или облачная модель.

Модель загружается или вызывается только после согласия на разбор.

Концепция до реализации

Сначала предложение

  1. Браузер замечает 2–5 похожих товаров в обычных вкладках. В фоне определяет тип и готовит текст, без вызова модели.
  2. Один короткий поповер в верхнем правом углу области страницы, без нового знака в тулбаре. Не перекрывает другой поповер, не появляется во время ввода или на полноэкранной странице.
  3. Только вопрос, объяснение и «Сравнить». Клик мимо, Escape, крестик или «Не сейчас» закрывают его. Для той же комбинации он не возвращается снова и снова.
  4. Повторный запуск — через существующую AI-панель как контекстное действие «Сравнить открытые варианты». Постоянной кнопки в хроме нет. Отключение предложений — в существующих настройках AI.

Затем помощь с выбором

  1. Саммари: в чём основная развилка и каких данных не хватает. Не заголовок «таблица» и не победитель без объяснения.
  2. До трёх советов по разным задачам: сэкономить, получить конкретную возможность, понять доплату. У каждого — причина, компромисс и раскрываемые основания.
  3. Отдельно — 1–2 существенные оговорки. Никаких выдуманных баллов, процентов уверенности или ранжирования по двум отзывам.
  4. Характеристики доступны вторым разделом. Для 4–5 вариантов советов не становится пять: оставляем главные сценарии, все товары доступны в фактах.

Факты, а не догадки

В этом макете используются только названия, цены и оценки с присланного скриншота. Память извлечена из заголовков, цена — из разметки; условия не подтверждены. Нет рекомендаций по камере и процессору: таких фактов на экране нет.

В реализации: видимые данные выбранного варианта важнее SEO. Для WB — адаптер открытой карточки и «О товаре». Саммари ссылается на найденные факты; непроверяемый совет не показывается. При изменении варианта результат помечается устаревшим, обновление — явное.

Стоимость и состояния

Один ограниченный запрос после «Сравнить»: сопоставление характеристик + краткий вывод + максимум три сценария. Используется настроенная модель, облачные вызовы учитываются в статистике. Вызовов в фоне и автоматической повторной генерации при каждом переключении вкладки нет.

Без модели показываем предложение подключить её и исходные факты. Если модель недоступна, не выдаём шаблон за AI-совет: остаются данные и возможность повторить. При обновлении прежний разбор остаётся доступным до готовности нового.

Визуальная опора

LibraryShell + panelIsland + panelRoom: земля вокруг, поле 16 px для тени, остров r20, непрозрачная поверхность, лестница теней и внутренний свет. Шапка — плакатный токен, как в библиотеке. Содержимое — 24 px; зазоры 8 / 12 / 16 / 24 / 32; вложенные коробки r12; контролы r8.

Цвета и шрифты встроены из реальных CSS-токенов проекта. Golos Text для интерфейса, Unbounded для героя и лиц карточек, JetBrains Mono для служебных подписей. Поповер — непрозрачный материал, r12, поле 12 и общий рецепт тени; без плакатных цветов.

Автоматическое предложение над страницей. Тулбар не получает новых кнопок.

Макет для обсуждения. Карточки — пример подачи на основе присланных данных, не готовый результат работающей модели. Изменений в интерфейс браузера этот документ не вносит.
