# Последний ограниченный этап разведки — 2 октября 2026

Один офлайн-проход: 20 синтетических документов и восемь запросов. Electron,
LLM и пользовательский профиль не запускались. Использован установленный
`franc-min` и существующий `shared/langDetect`; рабочие исходники не менялись.
На этом серия разведочных прогонов заканчивается.

## Результат

| Проверка | Результат |
| --- | ---: |
| Документы с размеченным основным языком | 14 |
| Ошибки определения по полному тексту | 4/14 |
| Ошибки определения по короткому фрагменту | 7/14 |
| Несогласие трёх ограниченных проб текста | 5/20 |
| Конкретная догадка на недостаточном материале | 4/5 |
| Английский fallback при `und` | 1/5 |
| Ложное требование языка при разборе вопроса | 3/8 |
| Пропущенное требование языка | 1/8 |

Полный текст: медиана 0,321 мс, p95 0,735 мс после импорта библиотеки.
Это один проход на небольших фикстурах, не оценка нагрузки большой истории
и не общая точность определения языка. Низкая цена вычисления не делает
результат достаточно надёжным для жёсткого исключения страниц.

Причины ошибок видны в сохранённом выводе:

- Украинский и болгарский `franc` распознал правильно, но политика перевода
  заменила их русским из-за кириллицы. Менять перевод ради поиска не требуется;
  для поиска нужен отдельный смысл языкового сигнала.
- Английский материал с русским меню получил русский итоговый язык, хотя
  исходный `franc` выбрал английский. На разных участках текста сигналы расходятся.
- Код внутри английского или русского материала определился французским.
  Фрагмент вокруг поискового совпадения не обязательно отражает язык статьи.
- Английская статья с французской цитатой получила французский язык даже
  по полному тексту. Несколько проб выявили конфликт, но не доказывают сами
  по себе, какой язык основной; новый порог в этом опыте не подбирался.
- Короткие «Battery care» и «Batterie lithium» получили румынский, скелетон
  «Loading… 74%» — нидерландский. Наличие конкретной догадки не означает
  подтверждённый язык материала.
- Пустой текст дал `und`, после чего `pickLanguage` вернул английский fallback.
  Это приемлемая запасная политика перевода, а не доказательство языка страницы.

Есть отдельно размеченные смешанный документ и конфликт HTML-подсказки
с текстом. Их нельзя решать слепым доверием одному атрибуту или большинству
проб. `declaredLang` задан в фикстуре как условный внешний сигнал; эта проверка
не извлекает его из реальных сайтов и не утверждает, что история уже его хранит.

Прежний пробный распознаватель условий проверяет наличие «английск», «немецк»,
«французск» где угодно в вопросе. Поэтому «французская литература», «немецкие
автомобили» и «английские сокращения в русском тексте» ошибочно стали требованиями
языка материала. Испанский не распознаётся вообще. Это проверка границ старого
стенда, не предлагаемый готовый парсер пользовательских намерений.

## Зафиксированное решение

Жёсткий языковой фильтр по одному 240-символьному фрагменту не внедрять.
Определение языка можно использовать как недорогой сигнал, но необходимо
отдельно представлять неподтверждённый/смешанный язык и отличать язык материала
от темы запроса. Это не требует немедленной миграции истории или увеличения
индекса. Перевод и его существующую политику не менять этим этапом.

Дальнейшая работа описана в [плане AI-поиска](../../docs/ai-history-search-plan.md).
Сырые данные — `history-language-edge.json`, корпус —
`scripts/fixtures/history-language-edge.mjs`, запуск —
`node scripts/history-language-edge.mjs`. Проверка подтверждает целостность
прогона; обнаруженные ошибки качества сохранены как наблюдения.

Синтаксис скриптов, сборка и типы обоих таргетов прошли. Полный `npm test`
не повторялся: изменены только диагностика и документы. Известные прежние
нарушения размеров файлов и непостоянный UI-таймаут описаны в
`history-numeric-validation.md`. Коммит выполняется с `core.hooksPath=NUL`,
обязательные проверки выполнены отдельно.
